markout.lob.itch

NASDAQ TotalView-ITCH 5.0 -> LOBSTER-format messages and books, for any day and ticker.

NASDAQ publishes full sample days of its ITCH feed (emi.nasdaq.com/ITCH/Nasdaq ITCH/): every message the exchange sent that day, for every stock, keyed by order reference number. convert streams one gzipped day once and, for the tickers asked for, rebuilds each book from the first add of the day. It writes what LOBSTER would: one row for every event in the regular session (09:30-16:00) that changes the levels visible levels or prints a trade, with the visible book after it. The fill simulator, the markouts and lobster.check_consistency run on it unchanged.

ITCH message -> LOBSTER type: A, F add order 1 submit X partial cancel 2 cancel D delete 3 delete E execution 4 execute (visible) C execution with price 4, at the resting order's limit price (where the depth changes) U replace 3 delete of the old order, then 1 submit of the new one (a replaced order loses its place in the queue) P execution of a hidden order 5 (NASDAQ reports the side as 'B' for these since 2014) Q opening/closing cross 6 H trading action 7, price -1 halt, 0 quotation only or paused, 1 resume Events before 09:30 and after 16:00 only update the book.

Correctness check: every execution, cancel, delete and replace must name an order added earlier the same day (books start empty every morning). Stats.unmatched counts those that don't; a correct parse of a full day has none.

python -m markout.lob.itch data/raw/itch/01302019.NASDAQ_ITCH50.gz --tickers AAPL,MSFT

def audit(chunks) -> dict:

Track every order of every stock through a whole feed and count references to unknown orders.

The conversion above checks the stocks it converts; this checks the file: every execution (E, C), cancel (X), delete (D) and replace (U) of the day, for all symbols, must name an order that was added (A, F, or a replace) earlier and still has shares left.

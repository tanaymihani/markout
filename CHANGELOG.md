# Changelog

All notable changes to this project are listed here. Versions follow
[semantic versioning](https://semver.org/); the numbers in the reports are regenerated by
`make report` and are not part of the version.

## [1.1.0] - 2026-10-25

### Added

- The desk runs on the site, in the visitor's browser, on a fictional 8-market scenario:
  [tanaymihani.github.io/markout/desk](https://tanaymihani.github.io/markout/desk/).
  Pyodide (CPython on WebAssembly) runs the desk's own Python in the tab, so every visitor
  gets a private paper-trading sandbox, nothing is sent anywhere, and nothing needs hosting.
  The site's hero and desk section link to it.
- `cup.sandbox`: the sandbox shared by the in-browser desk (`cup.browser`) and the HTTP
  server (`cup.public`), so both answer the page's requests with the same code.
- Tests: the in-browser desk's routes, its bundle (run on its own, without the repository),
  the freshness of the page and the bundle, and the desk in Chrome on Pyodide.

### Changed

- Hugging Face Docker Spaces now need a paid plan, so `deploy/README.md` describes the
  in-browser desk as the free live demo and the Docker image for self-hosting.
- The desk pages carry the site's icon (no more favicon 404).

## [1.0.0] - 2026-10-25

The first release: six studies, the tools behind them as a usable package, and the
engineering to keep both honest.

### Research

- Six reports, each generated from code and fixed seeds: the closing auction (01),
  queue-position fills on LOBSTER data (02), competition between market makers (03),
  delta hedging (04), sizing for a top-three contest (05) and the S&P volatility premium (06).
- Scripts behind the fill-model paper: fee and rebate sensitivity, robustness checks,
  tables and figures (`paper/scripts/`).

### Tools

- `markout` command: `fills` runs the touch, FIFO and trade-through fill models on any
  LOBSTER day and prints fill rates and markouts; `sharpe` gives a bootstrap interval,
  PSR and the Deflated Sharpe; `pbo` the probability of backtest overfitting; `kelly` the
  stake for a binary contract; `status`, `report`, `site`, `readme` and `desk` wrap the
  project's builds.
- `lobster.read_csv` reads the two files LOBSTER delivers, for any ticker, date or depth.
- The fill simulator in Python (reference) and C++17 (pybind11, bit-identical, about a
  second for a full day).
- `markout.evaluation`: trial registry, Deflated Sharpe, PBO by CSCV, stationary block
  bootstrap, a run-once holdout guard, Diebold–Mariano.
- [USAGE.md](USAGE.md) with examples that run in the test suite.

### Desk

- The Predictions Cup desk: references from Polymarket, Kalshi, Manifold, options and
  earnings history; a matcher that only suggests; log-odds pooling with the contest price;
  Kelly sizing capped by the book; approval with a last look; a kill switch; a decision
  journal that scores forecasts when markets resolve.
- A paper exchange implementing the contest interface, and an offline scripted demo.
- The hosted desk (`python -m markout.cup public`): a private sandbox per visitor, header
  sessions, eviction and expiry, rate limits, a hash-based Content-Security-Policy, JSON
  logs; a Docker image with pinned, hashed dependencies; a workflow that deploys it to a
  Hugging Face Space.

### Site

- An interactive page on GitHub Pages: a queue simulator, the real fills, the cost of the
  auction strategy, Kelly sizing on fat tails, a market-making game, and a recorded demo.
  The labs' JavaScript is tested against the Python implementation.

### Engineering

- mypy over the whole package, ruff lint and format, a stub for the C++ extension.
- CI on locked dependencies: lint, types, tests with a coverage floor, browser tests in
  Chrome, a container smoke test. CodeQL, Dependabot for actions and the base image, and
  a pre-commit configuration.
- Tests that fail when the site or the usage guide drift from the code.
- MIT licence.

### Known limitations

- The live contest adapter (`cup.api.LiveAPI`) is not written: the platform documents its
  API only to registered participants. The desk runs on the paper exchange until then.
